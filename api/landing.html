Simple Integration

Get started in minutes with our straightforward API

# 1. Start the gateway
$ docker-compose up -d

# 2. Login and get JWT token
$ curl -X POST http://localhost:8000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin"}'

# 3. Send MCP request through gateway
$ curl -X POST http://localhost:8000/mcp/my-server \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "method": "tools/list",
    "params": {},
    "id": "1"
  }'

# ✅ Request validated, authenticated, rate-limited, and logged!
